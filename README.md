# 🎃 借り人競争 早押し

**101 Hakatamingle ハロウィンイベント（2026年）** で使った、チーム対抗「借り人競争」用の早押しWebアプリです。

お題に合う人を会場で見つけて連れてきたら、チームのスマホで「回答する！」を押します。
受付順はリアルタイムで司会画面とスクリーンに表示され、司会がOK / NGを判定して得点が決まります。

## 画面

| 画面 | URL | 使う人 |
|---|---|---|
| チーム | `#team` | 参加者（リストバンドの色でチームを選ぶ） |
| 司会 | `#host` | 司会・運営（パスコードで保護） |
| スコア | `#score` | 会場スクリーンへの投影用 |

## 主な機能

- 最大10チーム、1ラウンド2分、3〜10ラウンド
- 1〜3位に 3 / 2 / 1 点
- 同じチームのスマホが同時に押しても、受け付けるのは1台だけ
- 受付時刻はサーバーの時計で決めるので、スマホの時計のずれに左右されない
- 日本語・英語の併記

## 技術構成

- フロントエンド：HTML / CSS / JavaScript（1ファイル）、GitHub Pagesで公開
- バックエンド：Supabase（Postgres + Realtime）
- `setup.sql`：データベースのテーブル・関数・権限の設定
